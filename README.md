# π 与圆 · 一个常数的两千年

单页静态站点，零依赖，双击 `index.html` 即可在浏览器打开，断网可用。

版式按印刷品来做：一张纸、一种宋体、正文连续排，图注里直接嵌控件，没有卡片、没有编号栏、没有等宽小标签。

## 页面结构

正文是一篇短文，末尾附五张可以动手的算具。

1. **数字墙** —— 开篇是 π 的前 900 位小数，用 Machin 公式在页面加载时现算（不是写死的），首字下沉。
2. **圆与 π** —— 周长与直径之比，无理数与超越数。
3. **几条要用的式子** —— 周长、面积、弧长、扇形、球体积、球表面积。
4. **把圆滚开** —— 拖动横线让圆沿基线滚动，已展开的弧被加粗，顶端有一条 `2πr` 的虚线作对照。图二。
5. **割圆** —— 刘徽与祖冲之；拖动边数看内接、外切多边形如何夹逼。图三。
6. **投针** —— 蒲丰投针；在画布上点一下落一根针，反推 π 并给出误差。图四。
7. **谁算过它** —— 从阿基米德到 62.8 万亿位，行首悬挂的纯文字年表。
8. **它在哪里** —— 齿轮、管道、导航、信号、统计、建筑里的 π。
9. **附：五个可以摸的图** —— 插值、拟合、求根、积分、微分方程。

## 五个算具

设定写在右侧边注（表达式、区间、方法），答案写在同一句图注里，改一个数，图与句子同时改口。

| 图 | 内容 | 怎么摸 |
|---|---|---|
| 图五 | 拉格朗日 / 牛顿插值 | 拖圆点、空白处单击加点、双击删点；改求解点 |
| 图六 | 1–6 次最小二乘 | 拖点看残差重排；滑杆改次数 |
| 图七 | 二分 / 牛顿求根 | 「单步」逐次推进，画出区间折半与切线 |
| 图八 | 梯形 / 辛普森积分 | 拖 n 看每一小块的真实形状 |
| 图九 | 欧拉 / RK4 | 两种方法同画，可播放积分过程 |

## 本地运行

直接双击 `index.html`；或在目录下起一个静态服务器：

```bash
python -m http.server 8000
```

`toolbox.html` 是旧地址的跳转页，会转到 `index.html#toolbox`。

## 技术说明

- 纯 HTML + CSS + 原生 JavaScript，零第三方依赖，离线可用
- 900 位小数用 BigInt 实现 Machin 公式现算（`16·arctan(1/5) − 4·arctan(1/239)`）
- Canvas 手写绘图：坐标变换、裁剪、整齐刻度（1/2/5 步长）、空心圆点
- 数据点直接操作使用 Pointer Events，支持鼠标与触屏
- 响应式：760px 以下边注落到正文下方，实测无横向溢出
