# π 与圆 · 一个常数的两千年

一个纯静态的数学科普单页，无任何依赖，直接用浏览器打开即可。

## 内容

- **圆与 π 的定义**：几何定义、无理数与超越数
- **圆的基本公式**：周长、面积、弧长、扇形、球体、椭圆
- **割圆术（可交互）**：拖动滑块改变正多边形边数，观察内接下界 `n·sin(π/n)` 与外切上界 `n·tan(π/n)` 如何夹逼 π
- **蒲丰投针（可交互）**：随机投针模拟，用相交频率反推 π
- **计算简史**：从莱因德纸草书到百亿亿位
- **π 的应用**：工程、信号、概率、物理、算法、天文

## 附带的数值工具箱

`toolbox.html` 是一个独立的数值计算工具箱，包含插值、曲线拟合、方程求根、数值积分与常微分方程五个模块。

## 本地运行

直接双击 `index.html`，或在目录下启动任意静态服务器：

```bash
python -m http.server 8000
```

## 技术说明

- 纯 HTML + CSS + 原生 JavaScript，零第三方依赖
- Canvas 绘制多边形逼近与投针模拟
- 响应式布局，适配桌面与移动端
