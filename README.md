# π 圆周率标本 · 数值工具箱

两个纯静态页面，零依赖，直接用浏览器打开即可。深色仪器风格：黑底、等宽标注、细网格、Canvas 实时绘制。

## 页面

### `index.html` — π 与圆

- **圆与 π 的定义**：几何定义、无理数与超越数
- **圆周展开（可交互）**：拖动转角，看圆周被一点点「摊」到直线上，滚满一圈正好 2πr
- **圆的基本公式**：周长、面积、弧长、扇形、球体、椭圆
- **割圆术（可交互）**：滑块改变正多边形边数，观察 `n·sin(π/n)` 与 `n·tan(π/n)` 如何夹逼 π
- **蒲丰投针（可交互）**：可直接在画布上点击投针，也可以用一键投 1000 根
- **计算简史**：从莱因德纸草书到百万亿位
- **π 的应用**：工程、信号、概率、物理、算法、天文

### `toolbox.html` — 数值工具箱

全部实时计算，改参数即时出结果，没有「开始计算」按钮：

- **插值**：拉格朗日 / 牛顿差商；图上拖动圆点改数据，空白处单击加点，双击删点
- **拟合**：1–6 次最小二乘；残差以竖线显示，R² 与方程同步更新
- **求根**：二分 / 牛顿；「单步」逐次推进，画面上直接画出区间折半与切线
- **积分**：梯形 / 辛普森；滑块调 n，画出每一小块的真实形状
- **微分方程**：欧拉 / RK4；两种方法同时画，可播放积分过程

## 本地运行

直接双击 `index.html`，或在目录下启动任意静态服务器：

```bash
python -m http.server 8000
```

## 技术说明

- 纯 HTML + CSS + 原生 JavaScript，零第三方依赖，离线可用
- Canvas 手写绘图：对数刻度、动态网格、裁剪、坐标变换
- 数据点直接操作使用 Pointer Events，支持鼠标与触屏
- 响应式布局，桌面与移动端均无横向溢出
