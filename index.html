π

一个常数，两千年

圆周率是圆的周长与直径之比。它不因圆的大小而改变，却让无数人为之计算一生。

01

圆与 π 的定义

把一枚硬币滚一圈，量出走过的长度，再除以它的直径——无论硬币多大，答案都接近同一个数。

几何定义

平面上到定点（圆心）距离等于定长（半径 r）的所有点构成圆。圆周长 C 与直径 d 的比值恒为常数，记作 π：

圆周率π = C / d = C / 2r
近似值3.1415926535…

它是什么数

π 是无理数：不能写成两个整数之比，小数不循环、不终止。1882 年林德曼证明它还是超越数—— 不是任何整系数多项式方程的根。这直接宣告了「化圆为方」不可能用尺规完成。

小数点后已知位数100 万亿位以上
常用近似22/7 ≈ 3.1429，355/113 ≈ 3.1415929
02

圆的基本公式

以下公式全部由 π 串联。设圆的半径为 r，圆心角为 θ（弧度制）。

圆周长C = 2πr
圆面积S = πr²
弧长l = rθ
扇形面积S = ½r²θ = ½rl
球体积V = 4/3 πr³
球表面积A = 4πr²
椭圆面积S = πab

阿基米德用「穷竭法」证明圆面积等于一个直角边为 r 与 C 的直角三角形面积，即 ½·r·2πr = πr²，这是最早的积分思想之一。

03

割圆术：用多边形逼近圆

刘徽与阿基米德各自想到同一件事：在圆内接正多边形，边数越多，周长越接近圆周长，π 的估计就越准。

内接正 n 边形（蓝）与外切正 n 边形（橙）把圆夹在中间。

04

蒲丰投针：用概率求 π

1777 年，蒲丰提出：向画有等距平行线的平面随机投针，针与线相交的概率竟与 π 有关。于是抛针也能估 π。

线间距 d = 1，针长 L = 0.8d。红针为与线相交者。

理论概率 P = 2L/(πd)。L=0.8d 时 P≈0.509，故 π ≈ 2·0.8/0.509 ≈ 3.14。

05

计算 π 的简史

从几何到无穷级数，再到计算机，人类对 π 的追逐从未停止。

约公元前 1650 年

莱因德纸草书

古埃及人用 (16/9)² ≈ 3.1605 作为圆面积计算的常数。

约公元前 250 年

阿基米德

用 96 边形夹逼，得 3.1408 < π < 3.1429。

约公元 263 年

刘徽 · 割圆术

提出「割之弥细，所失弥少」，以 3072 边形得 3.1416。

约公元 480 年

祖冲之

给出 3.1415926 < π < 3.1415927，并提出密率 355/113。

1671 年

格雷果里－莱布尼茨级数

π/4 = 1 − 1/3 + 1/5 − 1/7 + …，π 首次与无穷级数相连。

1706 年

梅钦公式

π/4 = 4·arctan(1/5) − arctan(1/239)，把 π 算到 100 位。

1882 年

林德曼

证明 π 是超越数，化圆为方被判定为尺规不可能。

2019 年至今

超级计算机

Google 与瑞士团队先后把 π 算到 31.4 万亿、62.8 万亿、100 万亿位。

06

π 出现在哪里

π 远不止用于量圆。它藏身于概率、波动、信号与宇宙的方程里。

工程与制造

齿轮、管道、轮胎、卫星轨道的尺寸计算都离不开 π。

信号与通信

傅里叶变换中的角频率 2πf，是音频、5G 与图像压缩的基础。

概率统计

正态分布的密度函数含 √(2π)，中心极限定理因此处处可见 π。

物理波动

单摆周期 T = 2π√(L/g)，电磁波与量子波函数同样含 π。

数论与算法

π 的小数位被用作随机数检验、哈希测试与算力基准。

天文与宇宙

开普勒定律、引力波波形、宇宙学参数中都出现 π。
