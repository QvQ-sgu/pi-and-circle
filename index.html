01定义

圆与 π

把一枚硬币在直尺上滚一圈，量出它走过的长度，再除以它的直径——无论硬币多大，答案都接近同一个数。

几何定义DEFINITION

平面上到定点（圆心）距离等于定长（半径 r）的所有点构成圆。圆周长 C 与直径 d 的比值恒为常数，记作 π：π = C / d = C / 2r ≈ 3.1415926535…

它是什么数NATURE

π 是无理数：不能写成两个整数之比，小数不循环、不终止。1882 年林德曼证明它还是超越数——不是任何整系数多项式方程的根。这直接宣告「化圆为方」不可能用尺规完成。

02公式

圆的基本公式

以下公式全部由 π 串联。设圆的半径为 r，圆心角为 θ（弧度制）。

圆周长C = 2πr
圆面积S = πr²
弧长l = rθ
扇形面积S = ½r²θ = ½rl
球体积V = 4/3 πr³
球表面积A = 4πr²
椭圆面积S = πab

阿基米德用穷竭法证明圆面积等于直角边为 r 与 C 的直角三角形面积，即 ½·r·2πr = πr²，这是最早的积分思想之一。

04投针

1777 年，蒲丰提出：向画有等距平行线的平面随机投针，针与线相交的概率竟与 π 有关。于是抛针也能估 π。

06应用

π 出现在哪里

π 远不止用于量圆。它藏身于概率、波动、信号与宇宙的方程里。

01

工程与制造

齿轮、管道、轮胎、卫星轨道的尺寸计算都离不开 π。从一枚螺栓的牙距，到一条环形轨道的周长，π 决定了零件能否严丝合缝。

02

信号与通信

傅里叶变换中的角频率 2πf，是音频、5G 与图像压缩的基础。

03

概率统计

正态分布的密度函数含 √(2π)，中心极限定理因此处处可见 π。

04

物理波动

单摆周期 T = 2π√(L/g)，电磁波与量子波函数同样含 π。

05

数论与算法

π 的小数位被用作随机数检验、哈希测试与算力基准。

06

天文与宇宙

开普勒定律、引力波波形、宇宙学参数中都出现 π。
